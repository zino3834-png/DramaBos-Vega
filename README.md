# DramaBos for Vega

Vega provider project integrating two separate DramaBos sources:

- **DramaBox**
- **DramaBite**

The two sources must remain separate across catalogs, searches, details, episode lists, and playback. IDs and results from one source must never be mixed with the other.

## Project status

Repository setup is complete. Provider implementation is still a starter and must be checked against Vega's current provider interfaces and the live DramaBos API response formats before it is considered ready to use.
